# 能力矩阵与保真上限（对用户诚实声明，2026-10-29 实证版）

> 原则：先报上限再干活。**不写"做不到什么"，就等于承诺了全部。**
> 已实跑验证的格子标 ✅（2026-10-29，三次实跑：Q1 季度总结 docx + 荆门文旅 59 篇 md）。

## 保真级别定义

| 级别 | 含义 | 可判定标准 |
|---|---|---|
| 克隆级 | 样式定义层逐项继承 | XML part 语义一致 + 样式表逐项相等 |
| 样式级 | token 映射（字体/字号/色板/边距） | CSS 变量与 spec 逐项一致；字号 ±1px |
| 近似级 | 视觉反推（无样式源时的上限） | 色差可辨、字号 ±2px，须附差异声明 |
| 内容级 | 仅结构与文本，无样式承诺 | 结构命中率 ≥0.8 |

## 三条铁律

1. **md 永远不做样式目标**——无字体概念，承诺"做得像"必输。md 产物头部必须带样式说明引用块（见 render_md.py）
2. **pdf 作源一律先声明近似**——无样式定义层，字号色值靠视觉反推；扫描件（无文本层）直接 `E-SRC-NOTEXT` 拒收并给替代 ✅（S4 实证）
3. **像素级跨源物理不可达**——不承诺、不尝试、不暗示

## 已实证记录（保持更新）
