# 澄清话术手册（第 0 问 + 四问 + 打样协议）

> 一次性问完，不打断式连环追问。用户说「就这样直接出」→ 全部落默认并记 `probe_skipped: true`。

## 第 0 问（必问——教训 #1，2026-10-29 荆门文旅实跑代价换来的）

> 「这份新文档，**给谁看、拿来做什么**？」（例：给研发照着开发 / 给领导汇报 / 对外发给客户 / 归档留底）

用途直接决定：详细度分级、保真取向（对内重结构、对外重样式）、以及是否需要打样环。
**这一问没问，后面四问可能全问错方向。**

## 四问（顺序固定，措辞可调）

| 问 | 话术 | 备注 |
|---|---|---|
| Q1 目标格式 | 「最终要什么格式？docx / pptx / html / md（可多选）」 | md 主动声明"仅内容层" |
| Q2 保真级别 | 「要哪种像？」选项式：**结构像**（章节顺序一致）｜**样式像**（字体字号色板一致）｜**版式像**（页边距页眉页脚一致）｜**一模一样**。**每项注明该组合能否达到**（查 capability-matrix.md）；达不到的直接说物理不可达 + 建议替代 |
| Q3 内容与槽位 | 「新内容从哪来（贴给我/另一份文档/我口述）？骨架里哪些节**保留**、哪些**替换**、哪些**删除**？」 | 槽数断言的前置：替换节数必须与内容条数对齐 |
| Q4 固定块 | 「哪些内容必须**原样保留**（页眉页脚/免责声明/公司名/落款）？」 | 固定块进 clone 层，渲染不触碰 |

## 保真声明模板（Q2 报上限时直接抄）

> 「先说上限：你给的 {源格式} → 要的 {目标格式}，我能做到 **{克隆级/样式级/近似级/内容级}**
> （{一句原因：样式定义层可继承 / 需 token 映射 / pdf 无样式源只能反推 / md 无样式概念}）。
> {若近似}——色差可辨、字号 ±2px，我会随成品附差异声明。」

## 打样协议（四问之后必进，至多 2 轮）

1. 出样片：**目标通道**前 1–2 节（`probe.py`；html 冒充 docx 样片 = 违规）
2. 议价：按 `style-negotiation.md` 维度清单（按目标格式降维）让用户**指着改**
3. 必问一句：「这份新文档，是**完全照模板**，还是**以模板为底、往你要的方向调**？」
4. 改动回写 `spec.deviated_from`：`{field, source_value, new_value, user_words(用户原话)}`
5. 第 3 轮起：按第 2 轮定稿交付，声明「基于第 2 轮样片，未经本轮确认」

## 特殊分叉

- 「把这个文档更新一下」→ **改原件，拒绝**，分叉「先另存副本再跑本 skill」
- 只有参考件、没说目标格式 → 属于 ambiguous，进四问，不硬跑
- 覆盖已有文件 → 列文件等确认（`E-OVERWRITE-DENIED`）
