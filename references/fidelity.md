# 降级声明模板（近似交付时随成品附上）

> 触发条件：`E-FIDELITY-EXCEEDED` 且用户接受降级（拍板策略：近似可达 → 交付近似 + 本声明，不拒收）。

---

## 差异声明（随 {产物文件名} 附带）

1. **本次交付保真级：近似级**（你要求的是"{一模一样/像素级}"）
2. **为什么达不到**：{源格式} 没有{样式定义层/母版信息}，字号与色值只能视觉反推——色差可辨、字号 ±2px、页眉页脚位置为估算
3. **与参考件的可感知差异清单**：
   | # | 项 | 参考件 | 本产物 | 差异性质 |
   |---|---|---|---|---|
   | 1 | {主色} | {#xxxxxx} | {#yyyyyy} | 视觉反推色差 |
   | 2 | {正文字号} | {x pt} | {y pt} | ±{n}px 估算 |
   | … | | | | |
4. **想拿到更高保真的路径**：提供 {docx/pptx} 原始版本的参考件 → 可达 {克隆/样式}级
5. **本声明的取舍已由用户确认**（对话时间：{时间}）——`spec.deviated_from` 已记录本次偏离

---

## 使用注意

- 差异清单**逐项列**，不许写"整体接近"这种不可判定的话
- 表格行数 = 实际反推项数；没有把握的项写"未估算"而不是编数字
- 声明同时写进产物同目录 `差异声明.md`，并在交付消息里明示（不许藏在文件里）
